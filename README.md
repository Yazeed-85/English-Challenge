# YZ English — تعلّم وتحدَّ

موقع ثابت (GitHub Pages) لتعلّم مفردات الإنجليزية: **المستخدم أولًا**، والتحدّي مع الأصدقاء فوقه.
بلا خادم ولا بناء (build): ES modules + Firebase Realtime Database + GSAP.

## النشر
1. ارفع المجلد كما هو إلى GitHub Pages.
2. Firebase Console (مشروع `en-learning-6ff54`): فعّل **Anonymous** في Authentication، والصق `firebase.rules.json` في Realtime Database ← Rules ← Publish.
3. لتثبيته كتطبيق: الأيقونات في `assets/` و`manifest.webmanifest` جاهزة (iPhone: مشاركة ← إضافة للشاشة الرئيسية. الكمبيوتر: زر «تثبيت» في المتصفح).

## ما فيه
- **الرئيسية**: خطة اليوم، الهدف اليومي، السلسلة، تقدّم الإتقان، كلمات تحتاج انتباهك، دفتري، كلمة اليوم، السجل، الأصدقاء.
- **التدرّب**: مراجعة ذكية (تكرار متباعد)، كلمات جديدة، كلماتي، اختبار سريع، تحدّي السرعة، استماع، إملاء، أكمل الجملة، **لعبة التصاريف**، أخطائي، **قراءة فقرة**.
- **القراءة**: 40 فقرة مترجمة بأربعة مستويات. استماع جملة بجملة، ترجمة سطرًا بسطر، اضغط أي كلمة لمعناها/تصاريفها/ملاحظتها، أو اضغط مطوّلًا واسحبها إلى «دفتري».
- **دفتري**: الكلمات المعلَّمة 🟡 (أتعلّمها) تظهر صفراء في كل مكان، وعندما تجيب عنها صحيحًا في الاختبارات تتحوّل ✅ (تعلّمتها) وتبقى في الدفتر. + القاموس العام (225 كلمة) مع بحث عربي/إنجليزي ذكي (تكتب «قبول» فتجد accept، وتكتب accepted فتجد accept).
- **التصاريف**: كل فعل/اسم/صفة يعرض أزمنته وأشكاله بقواعد الإنجليزية مع الأفعال الشاذّة (`js/forms.js` و`js/data/irregular.js`).
- **الأصدقاء**: رابط دعوة شخصي (مرة واحدة)، أو إضافة بالمعرّف (طلب يقبله الطرف الآخر)، ثم تحدٍّ بلا روابط.
- **التحدّيات**: كلمات ١٠/٢٠/٣٠ تبدأ سهلة جدًا (كلمة ← معناها) وتتدرّج، مع كشف المعنى والمثال بعد كل سؤال. و**قراءة معًا**: لكل لاعب فقرة بنفس المستوى (أثناء مكالمة).

## إضافة محتوى
- كلمات: `js/words.js` (سطر لكل كلمة، لا تغيّر كلمة موجودة). مفردات أساسية للنقر داخل الفقرات: `js/data/basic.js`.
- فقرات: آخر `js/data/passages.js` (5 جمل إنجليزية و5 ترجمات، بنفس الترتيب).

## الهوية والبيانات
معرّف عام (12 حرفًا) مرتبط بحساب Firebase المجهول، ورمز استعادة في «أنا». التقدّم محلي أولًا ويُنسخ احتياطيًا للسحابة (`priv/<معرّفي>`). القواعد: `link/keys/proof/pub/pres/priv/inv/friends/freq/inbox/duels`، والخبرة في `pub` لا تزيد أكثر من 300 لكل كتابة.

**حدود**: بلا خادم لا يمنع الغش بالكامل؛ القواعد تمنع انتحال الهوية وتعديل إجابات الغير وتضخيم الخبرة دفعة واحدة. الترجمة الآلية لكلمة غير موجودة في القواميس (MyMemory) اختيارية وتحتاج إنترنت ويجب مراجعتها.
