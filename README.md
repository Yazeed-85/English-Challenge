# English Challenge 2 — تعلّم وتحدَّ

موقع ثابت (GitHub Pages) لتعلّم مفردات الإنجليزية: **المستخدم أولًا**، والتحدّي مع الأصدقاء ميزة فوقه.
بلا خادم ولا بناء (build): ملفات ES modules + Firebase Realtime Database + GSAP.

## التشغيل
1. ارفع المجلد كما هو إلى GitHub Pages.
2. في Firebase Console (مشروع `en-learning-6ff54`):
   - Authentication → Sign-in method → فعّل **Anonymous**.
   - Realtime Database → Rules → الصق محتوى `firebase.rules.json` ثم Publish.
   - (اختياري) Authentication → Settings → Authorized domains: أضف نطاق موقعك.

## الفكرة
- **محليًا أولًا**: التقدّم (البطاقات، الملاحظات، السجل، الخبرة، السلسلة) يُحفظ في المتصفح ويعمل بلا إنترنت، وتُنسخ نسخة احتياطية للسحابة تلقائيًا.
- **التكرار المتباعد (لايتنر)**: صناديق 0–5 بفواصل 0/1/3/7/14/30 يومًا. الخطأ يُنزل الصندوق بدرجتين، والصواب يرفعه.
- **الرئيسية**: خطة اليوم (مراجعة مستحقّة / كلمات جديدة)، الهدف اليومي، السلسلة، تقدّم الإتقان لكل مستوى، كلمات تحتاج انتباهك، كلمة اليوم، سجلّ الجلسات، الملاحظات، الأصدقاء.
- **أنماط التدرّب**: مراجعة ذكية، كلمات جديدة، اختبار سريع، تحدّي السرعة، استماع، إملاء، أكمل الجملة، أخطائي.
- **225 كلمة** في 4 مستويات (A2–C1) و9 مواضيع. أضف كلمات في `js/words.js` (سطر لكل كلمة؛ لا تغيّر كلمة موجودة).

## الأصدقاء بلا غرف ولا أرقام
- لكل مستخدم **رابط دعوة شخصي** (`#/join/<معرّف>.<رمز>`) يرسله مرة واحدة.
- من يفتح الرابط وينشئ حسابه يصبح صديقًا تلقائيًا للطرفين (كتابة ذرّية واحدة تتحقق منها القواعد برمز الدعوة).
- بعدها يظهر الصديق في القائمة ويُتحدّى بضغطة: يصله إشعار داخل التطبيق (صندوق وارد) ويقبل بلا رابط.

## المبارزة
- 8 أسئلة من **بذرة مشتركة** (يولّد الجهازان نفس الأسئلة بنفس الترتيب). كل لاعب يكتب إجاباته فقط (`ans/<معرّفي>/<رقم>` مرة واحدة)، والنتيجة تُحسب عند الطرفين من الإجابات: 10 نقاط + حتى 5 للسرعة. لا مضيف يقود اللعبة، فلا تتعلّق إن غاب أحد.

## الهوية والاستعادة
معرّف عام عشوائي مرتبط بحساب Firebase المجهول (`link/<uid>`)، ورمز استعادة (12 حرفًا) في «أنا». على جهاز جديد: «لدي حساب سابق» ثم الرمز. إن بقي الحساب المجهول في المتصفح بعد مسح التخزين المحلي، تُستعاد البيانات تلقائيًا.

## القواعد (firebase.rules.json)
`link/keys/proof` للهوية، `pub` بيانات علنية (الخبرة لا تزيد أكثر من 300 لكل كتابة)، `priv` نسخة المستخدم الخاصة، `inv` رمز الدعوة (غير مقروء)، `friends` و`inbox` و`duels` مقيّدة بالأطراف. اختُبرت بمحاكي targaryen (49 حالة قبول/رفض) وبالتطبيق كاملًا في متصفح حقيقي.

**حدود صريحة**: بلا خادم لا يمكن منع الغش بالكامل؛ القواعد تمنع تزوير هوية غيرك وتعديل إجاباته وتضخيم الخبرة دفعة واحدة، لكن لاعبًا يعدّل عميله قد يرسل إجابات أسرع من الحقيقة.
